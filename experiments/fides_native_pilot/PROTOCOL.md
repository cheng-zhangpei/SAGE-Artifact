# FIDES-native policy authoring pilot

This pilot asks whether SAGE can check and additively complete MiMo-authored
policies executed through the public FIDES pre-effect policy interface on
SAGE's existing benchmark.

It freezes 12 tasks before generation: six base workflows and six composition
tasks spanning 8--48 target dispatches. MiMo-v2.5 receives the public workflow,
concrete call interfaces, labels, and flow policy, but no confirmed
`Rd/Wr/Gen`, probe verdicts, or SAGE clauses. One response is requested per task
at temperature 0.2.

The public FIDES repository provides a tutorial implementation rather than the
paper's full AgentDojo runtime. This study uses the tutorial's native convention:
a policy consumes a labeled action trace and raises `PolicyViolation` before a
tool effect. It does not reproduce FIDES's AgentDojo ASR/TCR experiment.

The tutorial is single-agent and `ToolCall` has no agent field. The adapter
therefore registers each benchmark tool under trusted name `agent/tool` and
adds that mechanical name to its public tool entry as `fides_action_name`; it
keeps the original parameters in `ToolCall.arguments`. Event categories use
FIDES's `PowersetLattice`; `label.subset` is the set read or generated by the
resolved invocation. This adapter and SAGE's confirmed model are counted as
integration/modeling cost.

The final evaluator uses FIDES's native full-trace policy semantics. Generated
Python is loaded only after a constrained AST check, but arbitrary candidate
Python is not claimed to be formally verified. Candidate syntax and runtime
errors are reported separately.

The three arms are the native LLM candidate, the native candidate preceded by
a verified SAGE sidecar, and DirectSAGE alone, all at the same pre-effect FIDES
interface. The sidecar runs first and denies an invocation whenever the
model-derived rejection predicate matches; otherwise the native candidate sees
the complete trace. The completion is checked for every concrete action and
every subset of the finite label universe. This additive composition covers
candidate omissions while retaining its existing denials and runtime errors.

We report workflow-level DER and BBR on the frozen probes, plus candidate load
and runtime errors. The earlier `study.py` evaluator remains as a diagnostic of
a restricted memoryless policy fragment; its UNKNOWN counts are not used as
the final native-FIDES result.
